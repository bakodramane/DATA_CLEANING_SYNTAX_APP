# Methodology

This document will describe the statistical editing and imputation framework
used by the rule library.

Planned methodological anchors include:

- UNECE Generic Statistical Data Editing Models
- Fellegi-Holt edit and imputation principles
- De Waal, Pannekoek, and Scholtus on statistical data editing
- robust outlier detection methods
- missing-data diagnosis and multiple imputation

Rules should follow a review, selection, and treatment sequence. The default
behavior should flag and document potential issues before any automated
treatment.

Phase 0 does not implement methodology logic.
