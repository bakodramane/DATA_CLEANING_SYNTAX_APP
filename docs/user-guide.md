# User Guide

This guide will explain the workflow for statisticians using the application.

Planned sections:

- importing metadata
- reviewing variable types
- defining missing-value codes
- configuring skip patterns
- selecting cleaning options
- previewing the Cleaning Plan
- exporting SPSS, Stata, R, and Python syntax
- saving and reloading Cleaning Plan JSON

Phase 0 provides only the app shell and documentation skeleton.
